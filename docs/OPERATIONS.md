# 시험일 체크리스트

관리자 화면 기준으로 씁니다. 명령이 필요한 일은 `docs/SETUP.md`의 단계 번호를 적었습니다.

## 일주일 전

- [ ] 문제은행에서 이번 시험 문항이 모두 **사용 중** 상태인지, 그림이 잘 보이는지 확인
- [ ] 시험 개설: 제한 시간, 합격 기준(과목별 % · 평균 %), 셔플, 해설 공개 여부, 열리는/닫히는 시각, 유의사항
- [ ] **연습 응시**: 시험을 열고 직원 2명이 PC와 휴대폰으로 끝까지 풀고 제출 → 결과·해설이 기대대로인지 확인
  - 연습 응시를 하면 문항 구성이 잠깁니다. 확인 후에는 **새 시험을 다시 개설**하고, 연습 시험은 닫아 둡니다.
- [ ] 백업 덤프 받기(SETUP 16) — 시험 기간이 아닐 때
- [ ] 관리자 허용 목록(관리자 → 관리자 허용 목록)과 Cloudflare Access 정책 이메일이 같은지 확인. 그만둔 사람은 **정지**
- [ ] Sentry 알림 메일이 오는지(SETUP 13) 한 번 확인

## 전날

- [ ] 시험 코드를 수험자 안내문에 넣어 배포(코드는 시험 화면 상단에서 눌러 복사)
- [ ] 안내문에 넣을 것: 접속 주소, 시험 코드, 수험번호 형식(영문·숫자 16자 이하), 같은 수험번호·이름으로 다시 들어오면 이어서 풀 수 있다는 점, 휴대폰은 충전해 올 것
- [ ] 시험장 인터넷(와이파이) 확인. 같은 공유기에 몇 명이 붙는지 확인 — 100명이 넘으면 SETUP 14의 요청 수 한도를 올릴지 검토
- [ ] 새 코드를 배포하지 않기(배포 동결). 급한 수정이 아니면 시험 뒤로 미룹니다

## 시험 시작 30분 전

- [ ] 시험이 **열림** 상태인지, 열리는 시각이 맞는지
- [ ] 직원 휴대폰으로 시험 코드 입력 → 시험 정보 표(과목·문항 수·시간)가 맞는지까지만 확인(입장하지 않음)
- [ ] **응시 현황** 화면을 띄워 둡니다(새로고침 버튼으로 갱신)

## 시험 중

- [ ] 응시 현황에서 `응시 중` 인원이 출석 인원과 맞는지
- [ ] **진행률 0으로 오래 멈춘 수험자**: 화면이 안 넘어가는지 직접 확인
- [ ] **기기 전환**이 1 이상인 수험자: 다른 기기로 다시 들어온 것입니다(먼저 쓰던 기기는 멈춤). 의도한 것인지 확인
- 수험자가 "저장 안 됨" 표시를 보면: 와이파이 확인 → 화면의 "다시 저장" → 그래도 안 되면 새로고침(답은 서버에 남아 있음)
- 수험자 기기가 꺼지면: 다른 기기에서 **같은 수험번호·이름**으로 입장 → 이어서 풀기. 남은 시간은 서버 기준으로 계속 흐릅니다
- "이미 다른 이름으로 응시한 수험번호"가 뜨면: 수험번호를 잘못 넣은 것. 본인 번호 확인
- "요청이 너무 많습니다"가 뜨면: 1분 뒤 다시 시도. 여러 명이면 SETUP 14 한도 조정이 필요하다는 신호(시험 뒤)
- 시간이 끝나면 화면이 자동 제출합니다. 화면을 닫아 둔 수험자도 서버가 10분 안에 시간 종료로 제출 처리합니다

## 시험 끝난 뒤

- [ ] 응시 현황에서 `응시 중`이 0이 될 때까지 기다립니다(최대 10분). `시간 종료(처리 대기)`는 자동으로 제출됩니다
- [ ] 시험 **닫기**
- [ ] 성적 화면 → **엑셀 내려받기**. 파일에는 이름·수험번호가 있으니 보관 위치에 주의(내려받기 기록은 접속 기록에 남습니다)
- [ ] 문항별 정답률이 아주 낮은 문항(빨간 막대)은 정답 표기 오류가 아닌지 문제은행에서 확인
  - 정답을 고쳐도 **이미 끝난 시험의 점수는 바뀌지 않습니다**(응시 기록이 있는 문항은 새 버전으로 저장). 재채점이 필요하면 개발자에게 요청
- [ ] 백업 덤프 받기(SETUP 16)
- [ ] 보관 기간이 지난 시험은 최고관리자가 시험 화면 맨 아래 **시험 삭제**로 지웁니다(엑셀을 먼저 받아 둘 것, 시험 코드 입력 필요, 되돌릴 수 없음 — D1 Time Travel로 7일 안에는 DB 전체를 되돌릴 수는 있음)
- [ ] 최고관리자는 **접속 기록**에서 시험 전후 관리자 작업에 이상한 것이 없는지 훑어봅니다

## 장애가 나면

| 증상 | 먼저 볼 곳 | 조치 |
| --- | --- | --- |
| 전원이 접속 안 됨 | Cloudflare 상태 페이지, 대시보드 Workers → 로그 | 직전에 배포했다면 SETUP 17 코드 되돌리기 |
| 일부만 저장 실패 | 해당 수험자 와이파이 | 다시 저장 → 새로고침 → 다른 기기로 이어서 |
| 서버 오류(500) 안내 | Sentry 메일, 대시보드 로그 | 개발자에게 오류 내용 전달 |
| 하루 요청 한도 초과 | 대시보드 Workers → 사용량 | 무료 한도는 하루 10만 요청(한국 시간 오전 9시 초기화). 30명 시험 1회 ≈ 750건이라 정상 운영에서는 닿지 않음 → 비정상 트래픽 의심 |
