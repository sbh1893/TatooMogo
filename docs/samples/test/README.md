# 테스트용 문제지 (TAT-Q 자체 제작)

실제 문제지 샘플을 받기 전까지 2주차 PDF 분리 기능을 개발·측정하기 위한 문제지입니다.
문항(데모 20문항 + 그림 문항 6개)과 그림은 모두 직접 만든 것이라 저작권 문제가 없고, 저장소에 커밋해도 됩니다.
실제 문제지 PDF는 `docs/samples/` 바로 아래에 넣습니다(그쪽은 git 제외).

## 파일

| 파일 | 내용 |
| --- | --- |
| `TATQ_test_paper_A_text.pdf` | 텍스트형 PDF. 글자를 선택·추출할 수 있음. 그림은 실제 이미지(PNG·JPEG)로 들어 있음 |
| `TATQ_test_paper_A_scan.pdf` | 같은 문제지를 스캔한 것처럼 만든 이미지 전용 PDF. 글자 층 없음, 약간 기울어짐·회색 종이·노이즈 |
| `TATQ_test_paper_A_answers.txt` | 정답표 (`1-②, 2-④ …` 형식, 정답 일괄 입력 기능 시험용) |
| `TATQ_test_paper_A_truth.json` | 정답 데이터: 문항별 번호·과목·지문·보기·정답·그림 파일·묶음·보기 고정. 분리 정확도 측정 기준 |
| `images/` | 문제지에 들어간 원본 그림 |
| `generator/` | 문제지를 다시 만드는 스크립트 (Python + Playwright) |

## 문제지 구성 (A4 3쪽, 26문항)

- 2단 편집, 가운데 세로줄, 매 쪽 머리글(`문신사 모의고사 1교시 / A형`)과 쪽 번호(`- 1 -`)
- 첫 쪽 표지 상자(시험명, 교시, 성명·수험번호 칸)와 안내문
- 과목 머리줄: `제1과목 위생·감염관리 (1~7)` 등 4개
- 문항 번호 `1.` ~ `26.`, 보기 `①`~`⑤`

분리 규칙이 처리해야 할 경우가 일부러 섞여 있습니다.

| 경우 | 문항 |
| --- | --- |
| 보기가 한 줄에 여러 개 (짧은 보기) | 3, 9, 12, 13 |
| 보기가 두 줄로 넘어감 | 11, 23 |
| 지문이 여러 줄 | 다수 |
| 지문에 그림(도식) | 13 (피부 단면, A~E 표시) |
| 지문에 사진 | 19 (선이 번진 피부 사진, JPEG) |
| 보기가 그림 | 20 (바늘 배열 그림 5개, 2열 배치) |
| 묶음 문항 (공통 지문 + 그림) | 6~7 (`※ [6~7] …` 상자 + 멸균기 화면 그림) |
| 보기 고정 (`①~④ 모두`) | 26 |
| 머리글·쪽 번호·과목 머리줄·표지 (문항이 아닌 글자) | 모든 쪽 |

## 분리 정확도 측정 방법 (제안)

`truth.json`과 분리 결과를 비교해 문항별로 아래를 확인합니다.

1. 문항 수와 번호가 맞는가 (26개)
2. 지문 글자가 맞는가 (공백 정규화 후 비교)
3. 보기 수와 각 보기 글자가 맞는가
4. 그림이 있는 문항에 그림이 붙었는가 (13, 19, 6~7 묶음, 20번 보기)
5. 정답표 붙여넣기 후 정답이 모두 맞는가

머리글·쪽 번호·과목 머리줄이 지문이나 보기에 섞이면 틀린 것으로 봅니다.
